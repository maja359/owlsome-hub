File colour

The file colour changes what you see above and what you get out of it: PNG comes out transparent at 1600 px wide in that colour, and Copy SVG gives you the same colour as vector. The originals in every brand colour sit in the Logo folder under Files.

Rules

  • The wordmark is the primary version. The symbol sits beside it, and never replaces it.
  • Clear space on all sides equals the cap height of the letters in the logotype.
  • Place it on a brand colour, on white, or on black.
  • On a photograph, only where legibility clearly holds.
  • Do not rotate, stretch or distort it.
  • Do not add a shadow, a 3D effect or an outline.
  • Do not reset the wordmark in another typeface.
  • Do not put anything inside the clear space.
  • Do not place it on a background outside the palette.

Set up Canva

Ten minutes once, and every future post starts on brand.

  1. Open Brand, then Brand Kits, and create one called KronLab.
  2. Upload the logo files from the Logo folder, the wordmark and the symbol, in Depth and in Mist.
  3. Add the palette colours by pasting each HEX. Name them Mist, Silver, Chilli, Olympic, Depth.
  4. Upload the fonts and set Figtree SemiBold as heading, Figtree Medium as body, Roboto Mono Medium as subheading. Leave Monument out, the logo is the only place it belongs.
  5. Delete every default colour and font Canva added, so nobody picks one by accident.

Font upload needs Canva Pro. Without it, keep the logo as an image and pull Figtree and Roboto Mono from Canva's own font list, both are there.

What this kit is

Two separate jobs, two different tools. The Brand Brain writes words in the brand voice. The prompt bank makes pictures. Nothing here needs a designer, but you do need the right tool for each half, and they are not the same tool.

Words: the Brand Brain

Works in Claude and in ChatGPT. Set it up once and it lasts.

  1. Copy the file with the button below.
  2. In Claude, open Projects, create one called KronLab, and paste it into Project instructions. In ChatGPT, create a Project and paste it into Instructions, or use Customise ChatGPT.
  3. Work inside that project from then on. Ask for a product description, a launch email, ten captions, a pack panel. It checks itself against the brand rules before it answers.
  4. When something reads off brand, say so. It will tell you which rule it broke and rewrite.

Pictures: how to make one

  1. Download the files first. Below this you have the products and the faces. Click the ones the prompt names and they save to your computer. Do this before you open the chat.
  2. Start one new chat and keep it open. Everything you make today goes in this one chat, because that is what keeps the packaging identical from shot to shot.
  3. Attach the images in the order the prompt asks for, using the paperclip. When a prompt names a face and a product, the face goes first and the product second. The order is not cosmetic: the prompt says FIRST and SECOND, and the tool matches them by position.
  4. Paste the prompt with the Copy button, unchanged, and send. Do not add the product description yourself. The reference image already carries the shape, the colour and the label, and describing it in words on top of that is what makes labels come out wrong.
  5. Look at the label before you keep anything. If the text on the pack has gone crooked or turned into nonsense letters, throw that image away and send the prompt again. Do not retouch it and do not publish it.
  6. For the next shot, stay in the same chat. Attach only the new face, and write: same product as before. Then paste the next prompt.
  7. Change the face every few shots. Four men, four files. Two of them never appear in the same picture.
  8. Add any text in Canva afterwards, never in the prompt. Headlines, prices, claims, the logo, all of it goes on top later. Image tools spell badly and will invent a claim you cannot stand behind.
If a generation comes out wrong twice in a row, the fix is almost never a longer prompt. Start a fresh chat, attach the product again, and send the prompt on its own with nothing else in the conversation.
