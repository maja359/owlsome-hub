Which colour sits on which

  • Vapour and Ivory carry most surfaces. Oxblood (ref. PANTONE 7421 C) is the colour of the pack and of text on light grounds.
  • Rouge is the one bright accent: the monogram and single highlights, never large areas of text.
  • On Oxblood, Dark Maroon and Noir, type and logo turn to Vapour.
  • Flat colour only. No gradients, no gold, no hot pink.

The range

Three sticks, one case. The ring at the base, the product name and the monogram on the cap top carry the colour of the formula inside.

  • The case, the wordmark and the layout never change between products.
  • Only the ring, the product name and the cap monogram change colour, so the three can be told apart at a glance.

Clear space

  • Keep the height of the letter a free on every side.
  • No text, line, image or graphic inside that space.
  • On the stick the wordmark runs vertically, reading from the base upwards.

Ready to use

Never

  • Place it on a colour outside the palette, or on a part of a photograph where it does not read.
  • Write the name with a capital IQ in the logo. In running text the brand is Balmiq.

Set up Canva

Ten minutes once, and every post after that starts on brand.

  1. Open Brand, then Brand Kits, and create one called Balmiq.
  2. Upload the logo PNGs from the Logo tab: the wordmark and the monogram, in Oxblood, Rouge and Vapour.
  3. Add the six palette colours by pasting each HEX. Name them Noir, Dark Maroon, Oxblood, Rouge, Ivory, Vapour.
  4. Upload the fonts. Set IvyPresto Headline Light as heading, Basis Grotesque Medium as subheading, Basis Grotesque Regular as body.
  5. Delete every default colour and font Canva added, so nobody picks one by accident.

Font upload needs Canva Pro and a desktop licence for each font.

Which tool does what

Words
Claude or ChatGPT

Product copy, captions, emails, replies. Load the Brand Brain once and everything comes out in the Balmiq voice, with product claims flagged for review. Either works, pick the one you already use.

Images
Gemini or ChatGPT

New settings, and women with the product, from the reference images below. Gemini takes the face and the product in one go. Gemini is free. ChatGPT works the same way, but its free plan allows only a few uploads a day, so it suits a paid plan. Use one face per image. The women are AI stand-ins for now. After the photo shoot the faces are replaced with the women from the shoot, and the prompts stay the same.

Text on images
Canva

Headlines, prices and claims. AI image tools misspell words, so the image always comes out clean and the text goes on in Canva, with the Balmiq fonts.

Claude does not make images. Gemini and ChatGPT can write too, but keep Balmiq copy in the tool with the Brand Brain.

Brand Brain

The brand's rules written for AI: voice, logo, colour, type and image world. It checks every request against the brand before it answers.

The brand instruction file
Set it up once, in the tool you use for words.
In Claude
  1. Go to claude.ai and sign in.
  2. In the left sidebar open Projects and create a new project called Balmiq.
  3. Inside the project, open the project instructions, paste the Brand Brain (Copy above) and save.
  4. Start every Balmiq chat inside this project. The rules load on their own, you never paste them again.
In ChatGPT
  1. Go to chatgpt.com and sign in.
  2. In the left sidebar create a new project called Balmiq.
  3. Open the project settings, paste the Brand Brain into Instructions and save.
  4. Start every Balmiq chat inside this project.

How to make an image

Each prompt below lists the files to attach. Attach them in that order: the face first, the product second. Product-only prompts take the product files alone.

In Gemini, free
  1. Go to gemini.google.com and sign in with a Google account.
  2. Start a new chat. Open the Tools menu and choose Create images.
  3. If the model menu offers a choice, pick the highest one your plan has. It keeps the label sharper.
  4. Click + and upload the files the prompt lists, in order.
  5. Copy the prompt from this page, paste it and send. Never describe the stick in your own words, the attached image does that.
  6. Ask again three or four times and keep the best frame. Open it and download it at full size.
  7. For the next image stay in the same chat, upload a different face with the product and paste the next prompt. One face per image, never two in a frame.
In ChatGPT, paid plan
  1. Go to chatgpt.com, sign in and start a new chat.
  2. Click + and upload the files the prompt lists, in order.
  3. Paste the prompt and send. If it replies with text, add: Create the image.
  4. To fix one part, open the image, select the area and describe the change. Everything else stays as it is.
  5. Open the image and download it.
Check every frame before you use it
  1. Read the label letter by letter against the reference: the product name, the short description and NET WT 0.52 OZ / 15 g.
  2. Check the pack: oxblood aluminium case, ribbed cap, the product name and a thin ring at the base in the product colour, the white balmiq wordmark running vertically, nothing added.
  3. If the label comes out wrong or the stick changes shape, cut the prompt to its first sentence and the last line, then add one sentence at a time.
  4. Never publish a frame with wrong label text or a changed pack. No second face in a frame, no testimonials, no before and after, and every headline or claim goes on afterwards in Canva.
