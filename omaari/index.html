Clear space

  • Keep three times the height of the word PARFUMS free on every side.
  • No text, line, tagline or image inside that space.
  • Symbol minimum on screen: 48 px. Below that, use the letter O.
  • The symbol alone is for the cap, the favicon and anything under 10 mm.

Ready to use

Never

  • Rotate, stretch, outline, add shadow or 3D, or reset it in another font.
  • Place it on a colour outside the palette, or on a busy part of a photograph.
  • Run it in Amparo Blue on a dark surface.

Set up Canva

Ten minutes once, and every post after that starts on brand.

  1. Open Brand, then Brand Kits, and create one called OMAARI.
  2. Upload the PNG logos from the Logo folder: vertical lockup, horizontal lockup and symbol, in Black and in Vapour.
  3. Add the five palette colours by pasting each HEX. Name them Vapour, Sandstone, Charcoal, Black, Amparo Blue.
  4. Upload the fonts. Set Hardcover as heading, Basis Grotesque Arabic as body and subheading.
  5. Delete every default colour and font Canva added, so nobody picks one by accident.

Font upload needs Canva Pro and a desktop licence for each font.

How to make an image

  1. Open one new chat in Gemini for the whole session.
  2. Attach the files the prompt lists, in that order: the face first, the product second. For product-only prompts, the product alone.
  3. Paste the prompt as it is. Never describe the bottle in words, the attached image does that.
  4. Run it three or four times and choose. This is selection, not one perfect shot.
  5. For the next image in the same chat, swap only the face. Use a different face for each image, and never two in one frame.
  6. If the label comes out wrong or the bottle changes shape, cut the prompt to its first sentence and the last line, then add one sentence at a time.
  7. Never publish a frame with wrong label text or a changed bottle. Headlines and claims go on afterwards in Canva.
