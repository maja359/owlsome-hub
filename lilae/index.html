Which colour sits on which

  • Coral does the recognition work: logo, vertical stripe and headlines.
  • Lilac and Oat are the grounds Coral sits on. Periwinkle is an extra, used sparingly.
  • Coral text on Lilac loses contrast at small sizes. Drop to white or Navy, or make the type bigger.

The range

The finished packs, photographed. Every new image of a product starts from these.

  • The vertical lilæ wordmark and the Coral print run on every pack.
  • The body colour and the cap tell the products apart: Coral and Lilac for the cleanser, Lilac and a white sphere for the mist, a clear jar with Coral for the moisturiser.
  • Product names and formats are set in Apercu Pro, the small uppercase lines in Brandon Grotesque.

Clear space

  • Keep the height of the letter l free on every side.
  • No text, tagline, line or image inside that space.
  • The wordmark and the æ icon are never locked up together. Use one or the other.
  • The icon alone is for caps, seals, app icons and profile pictures.

Ready to use

Never

  • Rotate, stretch, outline, add shadow or 3D, or reset it in another font.
  • Place it on a colour outside the palette, or on a part of a photo where it does not read.
  • Add anything inside the clear space, a tagline included.

Set up Canva

Ten minutes once, and every post after that starts on brand.

  1. Open Brand, then Brand Kits, and create one called LILAE.
  2. Upload the PNG logos from the Logo folder: lilæ, lilae and the æ icon, in Navy, Coral and white.
  3. Add the colours by pasting each HEX: Coral, Lilac, Oat, Periwinkle, and Navy for text.
  4. Upload the fonts. Set Apercu Pro as heading and body, Brandon Grotesque as subheading.
  5. Delete every default colour and font Canva added, so nobody picks one by accident.

Font upload needs Canva Pro and a desktop licence for each font.

Which tool does what

Words
Claude or ChatGPT

Product copy, captions, emails, replies. Load the Brand Brain once and everything comes out in the LILAE voice. Pick the one you already use.

Images
Gemini or ChatGPT

New photos from the reference images below. Gemini is free and takes the face and the product in one go. ChatGPT works the same way, but the free plan limits uploads, so it suits a paid plan.

Text on images
Canva

Headlines, prices and claims. AI image tools misspell words, so the image always comes out clean and the text goes on in Canva, in the LILAE fonts.

Claude does not make images. Gemini and ChatGPT can write too, but keep LILAE copy in the tool with the Brand Brain.

Brand Brain

The brand's rules written for AI: voice, logo, colour, type and image world. It checks every request against the brand before it answers.

The brand instruction file
Set it up once, in the tool you use for words.
In Claude
  1. Go to claude.ai and sign in.
  2. In the left sidebar open Projects and create a new project called LILAE.
  3. Inside the project, open the project instructions, paste the Brand Brain (Copy above) and save.
  4. Start every LILAE chat inside this project. The rules load on their own, you never paste them again.
In ChatGPT
  1. Go to chatgpt.com and sign in.
  2. In the left sidebar create a new project called LILAE.
  3. Open the project settings, paste the Brand Brain into Instructions and save.
  4. Start every LILAE chat inside this project.

How to make an image

Each prompt below lists the files to attach. Attach them in that order: the face first, then the product. Product-only prompts take the product files alone.

In Gemini, free
  1. Go to gemini.google.com and sign in with a Google account.
  2. Start a new chat. Open the Tools menu and choose Create images.
  3. If the model menu offers a choice, pick the highest one your plan has. It keeps the label sharper.
  4. Click + and upload the files the prompt lists, in order.
  5. Copy the prompt from this page, paste it and send. Never describe the pack in your own words, the attached image does that.
  6. Ask again three or four times and keep the best frame. Open it and download it at full size.
  7. For the next image stay in the same chat, upload a different face with the product and paste the next prompt. One face per image, never two in a frame.
In ChatGPT, paid plan
  1. Go to chatgpt.com, sign in and start a new chat.
  2. Click + and upload the files the prompt lists, in order.
  3. Paste the prompt and send. If it replies with text, add: Create the image.
  4. To fix one part, open the image, select the area and describe the change. Everything else stays as it is.
  5. Open the image and download it.
Check every frame before you use it
  1. Read every label letter by letter against the reference: Gentle Reset Daily Cleanser 120 ml, Calm Mist Hydrating Spray 100 ml, Barrier Sorbet Water-Cream Moisturiser 30 ml, Developed for young skin. Moisturiser with an s.
  2. Check the packs: the Coral cleanser with the Lilac cap, the Lilac mist with the white sphere, the clear jar with the Coral lid, the vertical lilæ on each, nothing added.
  3. If a label comes out wrong or a pack changes shape, cut the prompt to its first sentence and the last line, then add one sentence at a time.
  4. Never publish a frame with a wrong label or a changed pack. No before and after, no result images. Headlines and claims go on afterwards in Canva.
