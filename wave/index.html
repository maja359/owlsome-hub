The violet gradient
Soft violet #BE7BB2 at the top into deep aubergine #2C0722 at the base, as printed on every carton. A fine grain in print and photography. Holds white type at any size.

Which colour sits on which

  • Mist and Beige carry most surfaces. Mulberry and Velvet are kept for the wordmark, type and the bottle. Cartons and key visuals run the violet gradient.
  • White type on Velvet, Mulberry and the gradient. Mulberry or Velvet type on Mist and Beige.
  • No blue, green, yellow or amber, anywhere.

The range

One colour story across every product. Size and format change, the colours do not.

  • The treatment bottle is always Mulberry with a white matte dropper and the white wordmark.
  • Cartons run the violet gradient. Accessories are white or clear with Mulberry details, and carry the wordmark.

Clear space

Ready to use

Never

  • Rotate, stretch, outline, add shadow or 3D, or reset it in another font.
  • Place it on a colour outside the palette, or on a part of a photograph where it does not read.
  • Run it in Mulberry or black on Velvet, Mulberry, Wisteria or the gradient.

Set up Canva

Ten minutes once, and every post after that starts on brand.

  1. Open Brand, then Brand Kits, and create one called Wave.
  2. Upload the wordmark PNGs from the Logo tab: Mulberry, white and black.
  3. Add the five palette colours by pasting each HEX. Name them Velvet, Mulberry, Wisteria, Beige, Mist.
  4. Upload the fonts. Set Ivy Presto Headline Light as heading, Söhne Kräftig as subheading, Söhne Buch as body.
  5. Delete every default colour and font Canva added, so nobody picks one by accident.

Font upload needs Canva Pro and a desktop licence for each font.

Which tool does what

Words
Claude or ChatGPT

Product copy, captions, emails, replies. Load the Brand Brain once and everything comes out in the Wave voice, with medical claims flagged for review. Either works, pick the one you already use.

Images
Gemini or ChatGPT

New photos from the reference images below. Gemini is free and takes the face and the product in one go. ChatGPT works the same way, but the free plan allows only 3 uploads a day and one image needs 2, so it suits a paid plan.

Text on images
Canva

Headlines, prices and claims. AI image tools misspell words, so the image always comes out clean and the text goes on in Canva, with the Wave fonts.

Claude does not make images. Gemini and ChatGPT can write too, but keep Wave copy in the tool with the Brand Brain.

Brand Brain

The brand's rules written for AI: voice, logo, colour, type and image world. It checks every request against the brand before it answers.

The brand instruction file
Set it up once, in the tool you use for words.
In Claude
  1. Go to claude.ai and sign in.
  2. In the left sidebar open Projects and create a new project called Wave.
  3. Inside the project, open the project instructions, paste the Brand Brain (Copy above) and save.
  4. Start every Wave chat inside this project. The rules load on their own, you never paste them again.
In ChatGPT
  1. Go to chatgpt.com and sign in.
  2. In the left sidebar create a new project called Wave.
  3. Open the project settings, paste the Brand Brain into Instructions and save.
  4. Start every Wave chat inside this project.

How to make an image

Each prompt below lists the files to attach. Attach them in that order: the face first, the product second. Product-only prompts take the product files alone.

In Gemini, free
  1. Go to gemini.google.com and sign in with a Google account. Editing your own photos needs an account holder aged 18 or over.
  2. Start a new chat. Open the Tools menu and choose Create images.
  3. If the model menu offers a choice, pick the highest one your plan has. It keeps the label sharper.
  4. Click + and upload the files the prompt lists, in order.
  5. Copy the prompt from this page, paste it and send. Never describe the pack in your own words, the attached image does that.
  6. Ask again three or four times and keep the best frame. Open it and download it at full size.
  7. For the next image stay in the same chat, upload a different face with the product and paste the next prompt. One face per image, never two in a frame.
In ChatGPT, paid plan
  1. Go to chatgpt.com, sign in and start a new chat.
  2. Click + and upload the files the prompt lists, in order.
  3. Paste the prompt and send. If it replies with text, add: Create the image.
  4. To fix one part, open the image, select the area and describe the change. Everything else stays as it is.
  5. Open the image and download it.
Check every frame before you use it
  1. Read the label letter by letter against the reference: Hair Loss Treatment, PERSONALISED BY A DERMATOLOGY CLINICIAN, 30 ML or 100 ML. British spelling, Personalised with an s.
  2. Check the pack: matte Mulberry glass, white dropper, the Wave wordmark, nothing added.
  3. If the label comes out wrong or the bottle changes shape, cut the prompt to its first sentence and the last line, then add one sentence at a time.
  4. Never publish a frame with wrong label text or a changed pack. Wave is a prescription service: no before and after, no result images, and every headline or claim goes on afterwards in Canva, after review.
